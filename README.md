# CITY RUSH / Bike District

Переработка трёхполосного раннера в велосипедную obby с социальным хабом.
**Статус: integration build; не подтверждённый release-quality релиз.** Код и сборка проверяются автоматически. Roblox Studio/клиент в среде разработки недоступны: физика, мобильное управление, внешний вид и многопользовательская игра требуют engine-playtest.

## Что реализовано

- Аркадный велосипед на стандартном Humanoid: штатный стик/WASD, прыжок Roblox и свободная камера. Удалена конфликтующая серверная Seat/AlignOrientation-сборка; модель приварена без массы и коллизий. Сервер проверяет бюджет перемещения и последовательность чекпоинтов.
- Три конечных мира: **Coastline**, **Sky Gardens**, **Afterhours**; по 12 именованных этапов. Шесть типов секций: дороги/подъёмы, виражи, мосты, разрывы, слалом и вращающиеся препятствия. Маршруты заданы в `Courses.lua`, без бесконечной случайной генерации.
- Чекпоинты, быстрый возврат, продолжение сохранённого заезда, таймер, персональные рекорды, бронза/серебро/золото, открытие миров.
- Хаб: 11 индивидуальных гаражей, коллекции велосипедов, посещение соседей, ателье, порталы миров, клуб гонок, ежедневные награды.
- Шесть велосипедов с разными характеристиками, пять уровней улучшений. Старые BMX/Street/Neon/Carbon и валюта переносятся из v2/v1; старые уровни выше пяти ограничиваются новым максимумом.
- Серверные гонки с очередью, общим отсчётом, таймаутом, местами и наградами. Характеристики участников одинаковые. Пока одна трасса для гонок — Coastline.
- Во время езды: компактная полоса прогресса и времени высотой 38 px и кнопка меню. Большие панели скрыты, низ экрана свободен под стандартные кнопки Roblox. Магазин, результаты и рейтинг доступны отдельно.
- Сохранения v3: `UpdateAsync`, блокировка сессии, повторы, миграция, защита от записи пустого профиля после ошибки чтения, параллельное закрытие сессий.

## Сборка и публикация

Сохранены исходные адреса публикации:

- Universe: `8860447734`
- Place: `79281925900541`
- GitHub secret: `ROBLOX_API_KEY`

**Pull request только проверяет и собирает артефакт.** Push/merge в `main` запускает прежнюю публикацию в Roblox. Секрет не извлекается и не меняется. Workflow можно запускать вручную; публикация разрешена только с `main`. Публикации сериализованы, чтобы более старая сборка не обогнала новую.

В Actions: открой запуск → `Artifacts` → `CITY-RUSH-place-79281925900541`. Архив содержит `CITY-RUSH.rbxlx`, который открывается в Studio. Окружение создаётся при **Play**, поэтому до запуска Workspace не содержит готовой карты. Для постоянного редактирования геометрии в Studio потребуется отдельный bake/export, он пока не реализован.

```bash
python3 tools/validate.py
python3 tools/test_luau.py --luau /path/to/luau --compile /path/to/luau-compile
rojo build default.project.json -o build/CITY-RUSH.rbxlx
```

Luau `0.739`, Rojo `7.7.0`. Тесты не эмулируют Roblox физику, рендер или сетевой scheduler.

## Управление

ПК: WASD и Space. Телефон/геймпад: штатные Roblox-стик и прыжок. Отдельных кнопок тормоза и прыжка нет. Камера управляется как обычная Roblox-камера. Возврат на чекпоинт и в гараж находятся в меню «•••». Таймер не останавливается при открытом меню.

## Визуальные границы этой версии

Окружение использует собственную геометрию из нативных деталей Roblox: фасадные ламели, остекление, террасы, растения, дорожную разметку и освещение. Велосипеды имеют полые колёса со спицами, трубчатую раму, педали, седло и вилку. **Финального MeshPart/PBR-набора и подтверждённого художником визуального качества здесь ещё нет.** Это не копия карт или Toolbox-моделей из референсов.

Музыкальная система подключена, но `Config.MUSIC_ID` пуст: предыдущий чужой asset ID не использован без проверки прав и доступности. Аудио, финальные меши, баланс, runtime/performance-проверки и визуальная приёмка перечислены в `docs/RELEASE.md` как незакрытая работа, а не объявлены завершёнными.

## Исправление управления и Toolbox

Сервер асинхронно загружает геометрию [BMX Bike, asset 404397280](https://create.roblox.com/store/asset/404397280/BMX-Bike) через `AssetService:LoadAssetAsync`; `AllowInsertFreeAssets` включён в place. Копируются только BaseParts и визуальные mesh/decal/surface-компоненты. Скрипты, сиденья, remotes и исходные constraints не используются. После загрузки обновляются витрины, активный велосипед меняется при следующем старте/чекпоинт-респавне.

Из внешней среды asset delivery вернул 401, поэтому загрузка и ориентация модели не подтверждены реальным клиентом. При ошибке/неподходящих размерах работает резервная геометрия. Статус в `ReplicatedStorage.BikeAssetStatus` (атрибут): Loaded / Unavailable / Invalid. Источник задаётся только в серверном модуле, клиент не может передать другой asset ID.

Референс интерфейса просмотрен по [скриншоту заезда](https://www.speedrun.com/Obby_But_Youre_on_a_Bike/runs/y4k9872m): узкий прогресс, свободная центральная область, действия у края экрана. Клавиатурная накладка на видео не является частью интерфейса игры.
